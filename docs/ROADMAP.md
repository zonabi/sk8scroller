# Roadmap

Each milestone ends with something you can hand to a friend. Task cards are in BACKLOG.md.

| | Milestone | Outcome | Cards |
|---|---|---|---|
| ✅ | **M0 Prototype (v0.1)** | Core loop playable in a browser: run, jump, grind, balance, switch-ups, air tricks, combos, bails, XP, 4 skaters. Placeholder art. | — |
| ▢ | **M1 Feel** | It's fun for 10 minutes on a phone. Tuned on device, sound effects, manuals, first-run tutorial, pause. | T-01 … T-06 |
| ▢ | **M2 Look** | Real pixel art: animated skaters, tiles, parallax city, bitmap font, juice. | T-07 … T-10 |
| ▢ | **M3 On the phone** | Capacitor iOS build on TestFlight with haptics, tilt verified, safe areas. | T-11 … T-13 |
| ▢ | **M4 Depth** | Special meter, loadouts, tagging, stairs/gaps/multi-level terrain, 3 districts. | T-14 … T-18 |
| ▢ | **M5 Retention** | Daily seed + leaderboard, missions, cosmetics, music. | T-19 … T-22 |
| ▢ | **M6 Launch** | Store page, trailer, analytics, crash reporting, Android. | later |

Rule of thumb: don't start M2 art until M1 says the grey-box version is fun. Art won't fix feel.
